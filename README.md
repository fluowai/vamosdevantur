# VanTur — Transporte e Turismo

Site institucional estático da VanTur, com imagens, galeria e orçamento pelo WhatsApp.

## Executar

Abra `index.html` no navegador ou execute `python -m http.server 8080` nesta pasta e acesse http://localhost:8080.

## Publicar

Envie `index.html` e a pasta `assets/` para a raiz da hospedagem. Não requer instalação de dependências ou build.

Inclui a versão atualizada dos contatos, endereços, redes sociais e fotos com placas ocultadas.
